# MAULI TRAVEL

MAULI TRAVEL is a cab and tour service website based in Buldana, Maharashtra.

## Services

- Hyundai Aura Cab Service
- AC Cab Booking
- Local & Outstation Travel
- Tour Packages
- WhatsApp Booking
- Date-wise Availability
- Admin Controlled Upcoming Tours

## Technology

- Python
- Flask
- HTML
- CSS
- JavaScript
